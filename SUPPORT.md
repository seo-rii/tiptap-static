# Support

## Questions

Use [GitHub Discussions](https://github.com/seo-rii/tiptap-static/discussions) for integration questions and design conversations. A focused issue is appropriate when a question identifies missing or incorrect documentation.

## Bugs

Use the bug report form and include a minimal reproduction, the exact import path, and all relevant Tiptap, framework, and adapter versions.

The project supports the latest published `tiptap-static` version. Compatibility fixes for older versions are not guaranteed before 1.0.

## Security

Never place a vulnerability report in an issue or discussion. Follow [SECURITY.md](SECURITY.md) for private reporting.
